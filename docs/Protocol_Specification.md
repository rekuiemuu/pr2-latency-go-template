# Протокол

Датаграмма: `type: uint8 | sequence: uint16 | payloadSize: uint16 | version: uint16 | payload`. Числа записаны в сетевом порядке байтов. Версия — 1, заголовок — 7 байт.

Тип 1 — PING: 8-байтовая метка `clientSendTimeUs`. Тип 2 — PONG: исходная метка клиента, `serverReceiveTimeUs` и `serverSendTimeUs` (всего 24 байта). Типы 3 и 4 зарезервированы для MOVEMENT/SHOOT из ПР1, но в измерении не используются.

RTT вычисляется по монотонной разности двух `time.Time` клиента. Серверные метки и Unix-микросекунды в пакете применяются только для проверки совпадения запроса и диагностики; синхронизация часов не требуется.

Короткий заголовок, неизвестный тип, неверная версия, несоответствие размера и неверная длина PING/PONG отклоняются до чтения полезных данных.
